      How it works
      
A conservative source-to-source translator.

      
do2R tokenizes Stata statements, applies command-specific translators, rewrites common expressions, and uses a separate Mata pass. The output favors data.table for data work and established R packages for models that have no close base-R equivalent.

      
Important: Stata and R differ in missing-value rules, factor-variable semantics, estimation defaults, weights, survey machinery, time-series settings, and package implementations. Review model results and every item in the review queue before relying on a migration.

      
For unsupported community-contributed commands or highly dynamic ado code, do2R keeps the original line in a TODO comment so the intent is not lost.
